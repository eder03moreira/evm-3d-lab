# EVM 3D Lab — Catálogo (protótipo estático)

Site responsivo com catálogo demonstrativo, pesquisa, categorias, seleção de cor/quantidade, lista de cotação e envio para WhatsApp.

## Abrir
Abra `index.html` no navegador ou publique os arquivos em hospedagem estática (Cloudflare Pages / GitHub Pages).

## Importante
- Os produtos e ícones são **exemplos ilustrativos**, não fotografias reais.
- A logomarca original ainda precisa ser fornecida e adicionada; o cabeçalho usa somente texto provisório.
- **Não há painel administrativo, banco de dados, login ou checkout nesta versão.** Para produção, essas funcionalidades exigem backend seguro e autenticação.
- Nenhum preço é exibido. O WhatsApp de cotação é +55 44 99862-4250.
- A publicação em domínio personalizado e os limites de planos gratuitos dependem dos fornecedores.
